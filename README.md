# Caido 简体中文界面补丁

适用于 **Caido 0.59.0** 的非官方简体中文补丁。通过 Caido 自带的 **Custom JavaScript（自定义 JavaScript）** 功能启用，不需要替换安装文件。

覆盖约 1,600 条界面词条，包括侧边栏、拦截、HTTP 历史、重放、自动化、项目、插件管理和常用设置。

## 安装

1. 下载仓库中的 [`caido-zh-CN.js`](./caido-zh-CN.js)，复制全部内容。
2. 打开 Caido 的 **Settings → Developer Settings → Custom JavaScript**。
3. 如果已有自定义脚本，请先备份；保留原脚本，并将本补丁添加在其后。
4. 点击 **Save**。汉化立即生效，下次加载界面时会自动启用。

## 恢复英文

1. 打开 **设置 → 开发者设置 → 自定义 JavaScript**。
2. 移除本补丁代码，保留你原有的其他脚本，点击 **保存**。
3. 在底部 **命令** 面板中执行 **Reload Window（重新加载窗口）**，重新加载界面即可，无需退出抓包实例。

## 工作方式

- 复用 Caido 内置的 Vue I18n 语言接口，在内存中注册中文词条。
- 对少量初始化后不随语言更新的菜单、按钮、表头和占位提示补充显示翻译。
- 不修改请求、响应、载荷或项目数据，不使用外部翻译服务，也不上传抓包内容。
- 不修改安装包、授权状态或套餐限制。

## 兼容性与限制

- 已在 Windows 版 Caido 0.59.0 验证主要界面显示和重新加载后的自动启用。
- 部分教程长文、内部错误信息、第三方插件自带界面仍可能为英文。
- 补丁依赖 Caido 的内部语言资源结构，版本升级后可能需要适配。
- 请只安装你信任并检查过的自定义脚本。
